# Code of Conduct

## Scope

This document applies to project discussions, issues, pull requests, review comments, documentation, and other project spaces.

## Expected behavior

- Be direct and technical when reviewing code.
- Criticize behavior, design, and implementation details rather than people.
- Provide enough context for maintainers and contributors to reproduce problems.
- Respect project scope: Toolkit Package Manager is a dependency manager for CMake projects, not a general build-system replacement.

## Unacceptable behavior

- Personal attacks, harassment, or repeated hostile comments.
- Publishing private information without permission.
- Intentionally misleading bug reports or security reports.
- Repeatedly pushing scope changes after maintainers have rejected them.

## Enforcement

Maintainers may edit, hide, close, or lock discussions that violate this document. Severe or repeated violations may result in removal from project spaces.
